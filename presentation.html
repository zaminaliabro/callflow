CallFlow

A Sales Call Management System — assign leads, run calls, log outcomes, and watch every call roll up into live sales dashboards and targets.

PostgreSQL Express React Node.js Prisma ORM JWT Auth Tailwind CSS Recharts
The Problem

Sales call teams run blind

  • Leads are tracked in spreadsheets and notebooks — calls get missed, follow-ups slip.
  • Managers have no live view of who is calling, what is converting, or who is behind target.
  • Assigning customers to agents is manual and messy; nobody owns the lead.
  • Monthly targets are guessed at, not measured.
The Solution

One loop, fully tracked

CallFlow turns the whole sales-call cycle into a single, auditable workflow.

Data Model

Three tables do the work

TableKey fieldsRelations
User name, email, passwordHash, role (ADMIN/AGENT), phone, monthlyTarget has many Customers, has many Calls
Customer name, phone, email, city, status, notes, lastCallAt, nextFollowUpAt belongs to an agent (User), has many Calls
Call status, notes, saleAmount, followUpAt, createdAt belongs to Customer + Agent

Logging a call is one transaction: it inserts a Call and advances the customer's status + lastCallAt.

Access Control

Two roles, clear boundaries

👑 Admin

  • Full team dashboard & reports
  • Create / edit / delete agents
  • All customers — add, edit, delete, re-assign
  • Company-wide call log
  • Set monthly targets

🎧 Agent

  • Personal dashboard & target progress
  • Only their assigned customers
  • Add customers (auto-assigned to self)
  • Call Console — log every outcome
  • No access to other agents' data

Highlight

The Call Console

  • Searchable customer list on the left, live customer card on the right.
  • One-tap outcome: Interested · Callback · No Answer · Not Interested · Sale.
  • Choosing Sale reveals a required amount field.
  • Optional follow-up date + free-text notes.
  • On save: the call is stored and the customer's status & last-call time move forward automatically.

🎯 Why it matters

The agent never touches a spreadsheet. Every dial becomes structured data the moment it happens — which is exactly what the dashboards and targets are built on.

Security

Built in, not bolted on

  • bcrypt hashes every password — plain text is never stored.
  • JWT bearer tokens signed with a server secret; short-lived and verified on every request.
  • Role middleware (requireRole('ADMIN')) guards admin-only routes.
  • Ownership checks — an agent physically cannot read or edit another agent's customers.
  • Zod validation on every write; bad input is rejected with a clear 400.
  • Secrets live in .env — git-ignored, never committed.

Run It

From clone to login

# 1 — Backend
cd server
npm install
cp .env.example .env            # set DATABASE_URL + JWT_SECRET
npx prisma migrate dev          # create tables
npm run db:seed                 # admin + 4 agents + demo data
npm run dev                     # API → :5000

# 2 — Frontend
cd client
npm install
npm run dev                     # app → :5173
